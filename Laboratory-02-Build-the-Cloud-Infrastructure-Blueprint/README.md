# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory focuses on investigating cloud infrastructure components and understanding how compute, storage, networking, and operating system resources work together in a Linux cloud environment.

## Objectives

- Investigate a Linux server running in a cloud environment.
- Identify compute, storage, networking, and operating system resources.
- Compare AWS, Microsoft Azure, and Google Cloud Platform.
- Design a simple cloud infrastructure.
- Practice technical documentation using Markdown.
