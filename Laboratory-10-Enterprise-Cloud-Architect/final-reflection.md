# Final Reflection: My Journey from Mission 1 to Mission 10
## Cloud Computing – CCM101

My journey from Mission 1 to Mission 10 has been a valuable learning experience. Throughout these activities, I gained a better understanding of cloud computing, its technologies, and how they are used in real-world situations. At the beginning, I was still learning the basic concepts of cloud computing, virtualization, and cloud infrastructure. As I progressed through each mission, I became more familiar with the tools and processes involved in building and managing cloud environments.

Each mission introduced me to new challenges and skills. I learned about cloud service models, infrastructure, networking, virtualization, and different cloud technologies. I also gained practical experience using tools such as Linux, GitHub, and VirtualBox. Some activities were challenging, especially when I encountered errors during installation, configuration, and troubleshooting. However, these experiences taught me to be patient, follow instructions carefully, and find solutions instead of giving up.

Mission 10, **The Enterprise Cloud Architect**, was one of the most meaningful parts of my journey because it allowed me to apply many of the concepts I had learned. I created an Ubuntu Server virtual machine using VirtualBox, installed Docker and Docker Compose, and deployed a multi-tier application using WordPress and MariaDB. I also configured persistent storage, set up the UFW firewall, and created a Bash script with a Cron schedule for automated database backups. These activities helped me understand how different components work together to build and maintain a cloud environment.

Looking back, I can say that I have improved not only my technical skills but also my problem-solving abilities and confidence. I realized that learning cloud computing is not just about memorizing commands or completing activities. It is also about understanding how systems work, troubleshooting problems, and applying what I have learned.

Overall, Missions 1 to 10 helped me grow as an IT student. I am proud of the progress I have made, especially because I experienced difficulties but continued learning until I completed the activities. This journey has motivated me to explore more about cloud computing and improve my skills in the future. I believe the knowledge and experience I gained will be useful in my future studies and career in the IT field.
