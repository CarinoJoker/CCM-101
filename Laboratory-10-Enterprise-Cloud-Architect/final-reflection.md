# Final Reflection
## Mission 10 – The Enterprise Cloud Architect

Completing Mission 10 helped me understand how cloud infrastructure works in an actual environment. Through VirtualBox, I was able to create an Ubuntu Server virtual machine and use it as the foundation of my CloudNova private cloud project.

One of the most important things I learned was how to use Docker and Docker Compose to deploy a multi-tier application. I successfully connected WordPress and MariaDB using a Docker network and configured persistent volumes to store application and database data.

I also learned the importance of server security. Configuring the UFW firewall helped me understand how to control incoming and outgoing network traffic. Creating a Bash backup script and scheduling it with Cron also showed me how automation can make server maintenance easier.

During the activity, I encountered configuration errors, particularly when setting up the Docker Compose YAML file. I learned that correct spelling and indentation are important when configuring services, networks, and volumes. Troubleshooting these errors helped me become more patient and careful.

Overall, this mission improved my confidence in working with Linux, virtualization, Docker, networking, and server administration. It also helped me understand the responsibilities of an enterprise cloud architect, especially in maintaining a secure, reliable, and organized cloud environment.

This experience gave me practical knowledge that I can apply to future cloud computing activities and projects.
